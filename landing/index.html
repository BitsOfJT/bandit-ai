What it is

Bandit is a command-line AI chatbot that runs entirely on your own machine through Ollama. Chat history stays on your hard drive — no cloud, no accounts, no telemetry. Switch personas, stream responses with ANSI-colored markdown, and manage models without leaving the terminal.

A browser-based web UI is in progress. The shipped, showcased interface today is the CLI.

Features

  • Three personas

    Cynical Cyber-Raccoon, Garbage Philosopher, and Smart Assistant — swap them mid-session.

  • Real-time streaming

    Token-by-token responses rendered as ANSI-colored markdown in your terminal.

  • Session management

    Save, load, rename, and switch between chat sessions. Everything stays local.

  • Model management

    Pull, switch, and tune models — temperature, top_p, context window — from inside the app.

  • Local & cloud models

    Run any local Ollama model, or browse and run Ollama cloud models when you want more horsepower.

  • Web UI coming soon

    A browser interface sharing the same cyberpunk aesthetic is in development.

Try it yourself

Bandit runs locally only — models live on your machine, so there's nothing to demo in this browser. Grab it from GitHub and run it on your own terminal. You'll need Ollama installed and at least one model pulled.

curl — macOS & Linux

curl -fsSL https://raw.githubusercontent.com/BitsOfJT/bandit-ai/main/install.sh | sh
bandit

Homebrew — macOS & Linux

brew install BitsOfJT/bandit/bandit
bandit
